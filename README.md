# ALBARKA P2P WALLET — V1

Non-custodial multi-chain wallet starter.

## Current V1 foundation
- Dark-blue ALBARKA branding
- Welcome screen
- Create New Wallet flow
- Import Wallet flow
- Security-first architecture notes
- Home dashboard UI
- Send / Receive / Swap placeholders
- Assets list
- Settings/security placeholders

## Important
This is the UI/application foundation, not a production-ready wallet. Do not use real funds until cryptographic key generation, secure storage, transaction signing, auditing, and platform security review are implemented and tested.

## Recommended next implementation
1. BIP-39/BIP-32/BIP-44 wallet generation
2. OS secure storage / hardware-backed protection
3. Testnet transaction signing
4. Ethereum/BNB/Bitcoin/TRON/Solana adapters
5. Security audit
6. Store compliance and publishing
